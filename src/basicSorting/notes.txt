# What is bubble sort?
bubble sort is a comparison based sorting algorithm.
IT works by repeatedly stepping through a list and then comparing adjacent elements.
and then swapping them if they are in wrong order.

Its worst case time complexity is O(n square) and it occurs when the array is in exactly in reversed order.
Its best case time complexity is O(n) and it occurs when array is already sorted and the algo just verifies this in a single pass.
and space complexity is O(1) because it operates directly on array in place and does not use extra space.

Because of its worst case huge time complexity, it is rarely used to sort arrays in java.
and even the built in Arrays.sort function is much better than this in terms of time complexity.
it can be used to
 -check if an array is already sorted.
 -on tiny datasets.

Its pluspoints are
 - useful when array is nearly sorted and just a few elements are at wrong position.
 - when a problem restricts to adjacent swaps only
 - if we need to sort k largest/ smallest elements
 - if int a1 = 2 and int a2 = 2, it does not change their relative order while sorting i.e. we need a stable sorting algorithm.
 - it is a stable sorting algorithm.
 - when we might need to shift non zero elements to end without disturbing their relative order

Note on "Rabbits and Turtles": 
In standard Bubble Sort, largest elements move to rightmost position first
small elements at the end of an array (called "turtles") move to the left by only one position per pass,
which severely degrades performance. 
In reverse variation where smallest elements reach left most position first, 
large elements near the beginning become the turtles, moving only one step right per pass.
Combining both directions leads to Cocktail Shaker Sort (Bidirectional Bubble Sort), 
this alternates left-to-right and right-to-left passes to solve this issue. 

note- insertion sort is strictly superior to bubble sort because it does all the tasks of bubble sort even much faster.

# cocktail sort

in standard bubble sort, the iteration occurs from left to right 
and the largest element is sorted first in the rightmost position
whereas in reverse sort, the iteration occurs from right to left
and the smallest element is sorted first at leftmost position
cocktail sort is the merged version of standard sort and reversed sort
in one outer iteration, firstly the inner loop runs as standard bubble sort and then as reversed one.
this improves the time taken. 

# What is selection sort?
Selection sort is a strainghtforward comparison based algorithm.
It work by repeatedly finding the smallest and largest elements form the unsorted part of array
and then swapping them with the first or last element.

Its time complexity is always O(n^2). in all cases- worst case, average case and even the best case.
and space complexity is O(1).

the total number of swapping in bubble sort in every single pass is usually more than one 
whereas in selection sort, each pass occurs with one single swapping
in bubble sort, sorting can occur faster than expected but not in selection sort
moreover, it is also an unstable sorting algo.

in bubble sort, number of passes can be reduced by optimization, but selection sort cannot be optimized to reduce any iteration
hence, its performance in time is even worse than bubble sort.

cases when selection sort can be most useful
- it has relatively less number of swaps so when memory writes are extremely costly, it is of great use.
This is the primary reason to choose selection sort over other algorithms. 
Selection sort makes a maximum of exactly n - 1 swaps (memory writes) to sort an array of n elements.
In contrast, Bubble Sort and Insertion Sort can perform up to O(n^2) swaps. 
In systems where writing to memory is significantly more expensive or damaging than reading from it, selection sort shines.
